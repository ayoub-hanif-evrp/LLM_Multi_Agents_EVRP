# Experimental protocol

One scripted B0–B6 comparison has been run on the four-node development repair. It used no live model. `docs/MANUSCRIPT.md` records the objectives. The sample size is 1, so the report does not call the difference significant. Arms share the repair evaluator. Native costs are not averaged across families.

The classical solver command still reports `llm_calls: 0` and `attribution: classical_baseline`. A live Gate 5 run has not been launched. Schneider RC2 is not used as a blind final test.
