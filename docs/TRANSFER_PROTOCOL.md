# Transfer protocol

An operator whose required capability is absent, or whose forbidden capability is present, is rejected before its applicability expression is scored. That rejection is not counted as a failed generalization.

`select_operator` can also keep the classical operator when a compatible rule scores zero or below, and it abstains when the rule is illegal. The decision reads numeric features supplied by the caller. It does not read an instance filename. A panel transfer experiment is not running.

Training, confirmation, and held-out partitions for a future operator archive are not declared yet. Schneider RC2 remains a previously inspected set and is not a blind final test.
