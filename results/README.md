# Results

Paper-facing artifacts live in `results/md/` (`REPORT.md`, `figures/`, `tables/`).

| Folder | Contents |
| --- | --- |
| `md/` | Campaign report, figures, literature tables |
| `manifests/` | Split (`split.json`) and instance SHA-256 (`instance_hashes.json`) |

Partitions: discovery (C1, R1), confirmation (C2, R2, RC1), held-out RC2. Confirmation and RC2 must not be used to evolve a solver. Spark-era F1=1.0 results used a hidden stitch and are **not** paper results.
